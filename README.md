# Boat Airdopes Joy Windows Test Documentation

## Overview

This repository contains test cases, test execution reports, and automation scripts for validating Boat Airdopes Joy Bluetooth earbuds on Windows systems.

## Test Scope

- Bluetooth Pairing
- Reconnection
- Audio Playback
- Volume Control
- Microphone
- Teams/Zoom Calls
- Battery Verification
- Connectivity Stability
- Stress Testing
- Negative Testing

## Test Environment

| Parameter | Value |
|------------|---------|
| Device | Boat Airdopes Joy |
| OS | Windows 11 |
| Bluetooth Version | 5.x |
| Test Tool | Python |
| Framework | Pytest |

## Test Categories

- Functional Testing
- Integration Testing
- Performance Testing
- Stress Testing
- Compatibility Testing

## Automation

Python scripts are available under the Automation directory.

```bash
pip install -r requirements.txt
pytest
```
