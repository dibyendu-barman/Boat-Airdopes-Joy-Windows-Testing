# BT_001 - Bluetooth Pairing Verification

## Objective

Verify Boat Airdopes Joy can successfully pair with a Windows PC.

## Priority

High

## Severity

Critical

## Preconditions

- Earbuds charged above 20%
- Bluetooth enabled on Windows
- Earbuds in pairing mode

## Test Steps

1. Open Windows Settings.
2. Navigate to Bluetooth & Devices.
3. Click Add Device.
4. Select Bluetooth.
5. Choose Boat Airdopes Joy.
6. Complete pairing process.

## Expected Result

- Earbuds appear in the device list.
- Pairing completes successfully.
- Status shows Connected.
